# 2026-10-21 자동 게시 예약 지연 복구

## 확인된 원인과 범위

- 한국 시간 09:44 확인 시 오늘 첫 09:17 예약 실행 기록이 없었습니다. 글·이미지 생성 단계에서 실패한 것이 아니라 GitHub가 예약 실행을 만들기 전 단계였습니다.
- 저장소는 공개·활성 상태이며 기본 브랜치는 main입니다. 워크플로는 main에 있고 `active`, Actions 권한은 활성 상태였습니다. 마지막 예약 실행과 일정을 수정한 계정은 모두 저장소 소유자였습니다.
- 오늘 자동 게시 이력과 사이트 최신글에도 새 글이 없었습니다. 직전 수동 게시 테스트는 성공 상태였습니다.
- GitHub는 예약 실행이 부하에 따라 지연되거나 누락될 수 있다고 안내합니다. 이번 지연의 GitHub 내부 원인까지는 제공된 실행 기록으로 확정할 수 없습니다. [공식 문제 해결 안내](https://docs.github.com/en/actions/how-tos/troubleshoot-workflows)
- 기존 구현은 하루 정확히 10번의 실행 기회만 있었고 보류·오류도 10회 한도에 포함했습니다. 따라서 실행 누락이나 검수 보류가 생기면 하루 10편을 보충할 수 없는 구조였습니다.

## 변경한 운영 방식

| 항목 | 변경 후 |
|---|---|
| 정상 게시 목표 | 한국 시간 09:17~18:17, 시간당 한 편씩 하루 10편 |
| 부족분 점검 | 09:02~22:47, 15분 간격 |
| 지연·보류·오류 | 다음 점검에서 다른 주제로 한 편씩 보충 |
| 저녁 보충 | 18:17 이후에도 당일 10편이 될 때까지 점검. 23시 이후 시작된 예약 실행은 생성하지 않음 |
| 중복 비용 방지 | 현재 시간대 목표를 채웠으면 API 호출 없이 종료 |
| 게시 상한 | 자동 게시 10편. 수동 자동 게시도 포함 |
| 생성 시도 상한 | 실패·검수 보류·중단을 포함해 하루 15회. 유료 API 호출 전에 시도를 main에 예약 |
| 승인·품질 | 기존처럼 자동 검수 통과 후 게시. 검수 기준과 이미지 생성 품질 유지 |
| 컴퓨터 | 계속 켜 둘 필요 없음. GitHub에서 실행 |

15회 시도 상한은 실패가 있어도 10편 게시를 보충하기 위한 여유분입니다. 단순 점검에는 OpenAI API 비용이 들지 않으며, 실제 보충 생성에는 비용이 발생합니다. 예약 서비스 전체 장애나 검수 실패가 반복되는 경우까지 하루 10편을 보장하는 설정은 아닙니다.

## 확인하는 방법

1. [자동 게시 실행 목록](https://github.com/increw01-alt/kv-gift-site/actions/workflows/board-drafts.yml)을 엽니다.
2. 실행 Summary에서 현재 시각의 목표와 게시 수, 완료 후 `오늘 자동 게시 n/10편, 생성 시도 n/15회`를 확인합니다.
3. `API를 호출하지 않았습니다`는 이미 목표를 채웠거나 시간·횟수 제한으로 생성이 필요 없었다는 뜻입니다.
4. 실제 게시 확인은 **공개 게시글과 배너 확인** 단계의 성공 여부와 게시글 URL을 봅니다.
5. 비용은 Summary와 [날짜별 실행 JSON](https://github.com/increw01-alt/kv-gift-site/tree/main/data/editorial_runs)에서 확인합니다. `generating` 상태가 실행 종료 후에도 남았다면 로그·Artifact에서 중단 여부를 확인하고, 예약 시점의 비용을 0달러로 판단하지 않습니다.

수동으로 누락분을 확인하려면 **Run workflow → catch_up=true, preview_only=false**로 실행합니다. 현재 시간대 목표를 이미 채웠다면 추가 생성하지 않습니다. 같은 실행의 Re-run은 유료 생성을 반복하지 않습니다.

## 검증

- 복구 실행 두 건은 이미지 검수에서 보류됐습니다. 원본 이미지를 직접 확인하니 외부 여백에 있는 로고를 상품권 위에 있다고 판정하는 등 시각적 근거와 맞지 않는 사유가 있었습니다. 승인 스타일 이미지를 검수 입력에 추가하고, 최종 검수만 `gpt-5.4-mini` low reasoning으로 분리했습니다. 모든 검수 항목을 통과해야 게시하는 기준은 유지합니다.
- 검수 모델의 입력·캐시·출력 토큰 단가와 사용량 기록도 추가했습니다. [OpenAI 공식 모델·단가 자료](https://developers.openai.com/api/docs/models/gpt-5.4-mini)
- 주기별 목표 계산, 검수 보류 후 보충, 게시 10편 상한, 생성 15회 상한, 유료 생성 전 예약, 재실행 중복 방지와 검수 입력·비용을 테스트합니다.
- 로컬 테스트는 API를 호출하지 않습니다. 실행 중단도 시도 횟수에 포함되도록 예약을 먼저 저장하는 동작을 검증했습니다.
- 공개 사이트 확인 결과와 실제 실행 링크는 복구 실행 검증 후 이 문서에 추가합니다.
