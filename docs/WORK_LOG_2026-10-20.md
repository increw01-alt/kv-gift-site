# 2026-10-20 작업 기록과 자동 게시 운영 안내

한국상품권거래소 [kv-gift.co.kr](https://kv-gift.co.kr/) 작업 기록입니다. 기준 시간대는 한국 시간(KST)입니다.

> 이 문서는 10월 20일 기준 기록입니다. 10월 21일 예약 지연에 대응해 점검 주기와 보충 한도를 변경했습니다. 현재 설정은 [10월 21일 복구 기록](AUTOMATION_RECOVERY_2026-10-21.md)과 [운영 안내](../tools/BOARD_AUTOMATION.md)를 확인하세요.

**현재 운영 기준: 하루 10회 글과 이미지를 생성하고, 자동 검수를 통과하면 별도 사용자 승인 없이 게시합니다.** 2026-10-20 사용자가 요청한 최종 방식이며, 이전의 “화·금 초안 생성 → PR 승인 후 게시” 방식보다 우선합니다.

## 1. 오늘 완료한 작업

1. OpenAI API로 글과 주제에 맞는 이미지 배너를 생성하고 사용량·예상 비용을 남기도록 구성했습니다.
2. 짧은 문단, 질문형 소제목, 번호·체크 표시를 사용하고, 게시판 성격에 맞춰 글과 이미지 소재를 다르게 구성했습니다.
3. 승인된 아이보리·네이비·골드 일러스트 스타일과 드라이브에서 받은 KV 로고를 이미지 생성의 참고 자료로 연결했습니다. 같은 그림을 반복 사용하지 않습니다.
4. 승인받은 상품권팁·공지사항·구매/판매 안내 글과 이미지를 게시하고 목록, 메인 최신글, 사이트맵을 갱신했습니다.
5. 매일 약 10편을 목표로 자동 생성·검수·게시하도록 변경했습니다. 주제 중복 확인, 새 주제 보충, 실패 기록, 같은 실행 재시도 시 중복 생성 방지를 포함합니다.
6. 실제 자동 게시 테스트를 완료했습니다. 공개 이미지 확인 중 발생했던 HTTP 403 문제를 수정했고, 같은 실행을 다시 확인할 때 API를 재호출하지 않도록 했습니다.
7. 게시된 주제 수가 늘어도 자동화 테스트가 실패하지 않도록 테스트 자료를 분리했습니다. 기존 검증 결과는 로컬 테스트 33개 통과입니다.

이 문서 저장 시에는 유료 API 생성이나 추가 게시를 실행하지 않았습니다.

## 2. 하루 10회 자동 게시 설정

| 항목 | 현재 설정 |
|---|---|
| 실행 위치 | GitHub Actions — 컴퓨터를 켜 둘 필요 없음 |
| 워크플로 | [게시판 글·이미지 자동 게시](https://github.com/increw01-alt/kv-gift-site/actions/workflows/board-drafts.yml) |
| 활성 상태 | 문서 작성 시 `active` 확인 |
| 실행 시간 | 매일 한국 시간 09:17, 10:17, 11:17, 12:17, 13:17, 14:17, 15:17, 16:17, 17:17, 18:17 |
| 첫 전체 정규 일정 | 2026-10-21부터 위 10개 시간대 |
| 수량 | 회당 1편, 하루 최대 10회 자동 생성 시도 |
| 게시 승인 | 자동 검수 통과 후 바로 게시. 별도 사용자 승인 불필요 |
| 글 모델 | 기본 `gpt-4.1-mini` — 초안·편집·검수·필요한 경우 주제 보충 |
| 이미지 모델 | 기본 `gpt-image-2`, `medium`, 1536×1024 PNG |
| 설정 파일 | [board-drafts.yml](../.github/workflows/board-drafts.yml) |
| 운영 설명 | [게시판 자동화 상세 안내](../tools/BOARD_AUTOMATION.md) |

실행 순서는 **주제 선택 → 글 초안 → 문장 편집 → 이미지 생성 → 글·이미지 검수 → GitHub main 반영 → 공개 글·이미지 확인**입니다.

GitHub 예약 실행은 지연·누락될 수 있습니다. 검수 보류·오류 기록도 하루 한도에 포함하므로, 실제 게시 수는 10편보다 적을 수 있습니다. 이미지를 만들지 못하면 본문만 게시하지 않습니다.

게시판은 상품권 TIP → 구매 → 상품권 정보 → 판매 → 공지 → 일반상식 → 자유게시판 → 협회 소식 순서로 순환합니다. 협회 소식은 확인된 자료가 있을 때만 작성하고, 자료가 없으면 건너뜁니다.

고객을 가장한 후기·문의는 만들지 않고 한국상품권거래소 운영팀 안내로 작성합니다. 실제로 확인하지 않은 수수료·정책·이벤트·제휴를 만들지 않습니다. 로고는 저장소에 보관한 승인본을 사용하며, 드라이브 파일 변경을 자동으로 가져오지는 않습니다.

## 3. 글마다 사용량·비용 확인하기

### 가장 간단한 확인 방법

1. [GitHub 자동 게시 실행 목록](https://github.com/increw01-alt/kv-gift-site/actions/workflows/board-drafts.yml)을 엽니다.
2. 확인할 날짜의 실행을 클릭합니다.
3. **Summary**에서 글·편집·이미지·검수 단계별 모델, 토큰 사용량, 예상 USD 비용을 봅니다.
4. 글과 이미지를 보려면 **Artifacts → `board-review-실행번호-시도번호`**를 내려받아 압축을 풀고 `index.html`을 엽니다. `review.json`은 검수 결과입니다.
5. 비용 원본은 **`board-api-usage-실행번호-시도번호` → `board-api-usage.json`**에 있습니다. Artifact 보관 기간은 90일입니다.

같은 실행을 재실행하면 새 생성 비용이 없을 수 있습니다. 이때 최초 생성 비용은 첫 번째 시도 또는 아래 영구 기록에서 확인합니다.

### 날짜별로 남는 비용 기록

[GitHub 실행 기록 폴더](https://github.com/increw01-alt/kv-gift-site/tree/main/data/editorial_runs)에서 날짜 폴더와 실행번호 파일을 엽니다.

경로: `data/editorial_runs/YYYY-MM-DD/실행번호.json`

| 확인 항목 | JSON 이름 | 의미 |
|---|---|---|
| 처리 결과 | `status` | `published`: main 반영, `held`: 검수 보류, `error`: 오류 |
| 게시글 주소 | `url` | 게시된 글 주소 |
| 예상 총비용 | `api_usage.estimated_total_usd` | 기록된 단가와 API 응답 사용량으로 계산한 USD 예상액 |
| 확인된 비용만 합산 | `api_usage.known_subtotal_usd` | 일부 비용을 확인할 수 없을 때 확인된 부분만 합산 |
| 단계별 내역 | `api_usage.records` | 모델, 입력·출력 토큰, 단계별 비용, 단가 기준일·출처 |

`null`은 비용 확인 불가를 뜻하며 0달러가 아닙니다. API 응답을 받지 못한 요청은 이 기록만으로 과금 여부를 알 수 없습니다. 기록을 main에 저장하기 전에 실패했다면 실행의 Artifact와 로그부터 확인합니다.

`published` 기록은 main 반영을 뜻합니다. 사이트 반영 여부는 실행의 **공개 게시글과 배너 확인** 단계까지 성공했는지 확인합니다. 실행 자체가 성공해도 보류·한도 초과로 새 게시글이 없는 경우가 있으므로 게시 수는 URL과 상태를 함께 봅니다.

## 4. OpenAI 계정의 사용액 확인하기

1. [OpenAI Usage](https://platform.openai.com/usage)에 로그인합니다.
2. 이 사이트에서 사용하는 API 키가 속한 조직과 프로젝트를 선택합니다. Usage 화면의 프로젝트 필터를 직접 확인합니다.
3. 확인할 날짜 범위를 선택하고 사용액과 모델별 사용 내역을 봅니다.
4. GitHub의 글별 예상액과 비교합니다. 같은 프로젝트에서 다른 테스트를 했다면 그 사용량도 OpenAI 화면에 합산될 수 있습니다.

OpenAI Usage는 **UTC**, 저장소 날짜 폴더는 **한국 시간** 기준입니다. 현재 정규 시간대 09:17~18:17 KST는 같은 날짜의 00:17~09:17 UTC입니다. 야간 수동 테스트를 비교할 때는 날짜 경계에 주의하세요.

대시보드에는 조직 소유자 또는 Usage 조회 권한이 필요합니다. 계정 사용액과 최종 결제·세금 내역은 구분해서 확인하세요. 이 작업에서는 계정의 실제 청구서를 조회한 것이 아니라 API 응답 기반 예상 비용을 기록했습니다. [OpenAI 공식 사용량 확인 안내](https://help.openai.com/en/articles/10478918-reviewing-api-usage-and-costs)

## 5. 중지·재개와 수동 테스트

1. **중지:** [자동 게시 워크플로](https://github.com/increw01-alt/kv-gift-site/actions/workflows/board-drafts.yml) → 우측 메뉴 → **Disable workflow**. 이미 실행 중인 작업까지 멈추려면 해당 실행에서 **Cancel workflow**도 선택합니다. 이미 사용한 API 비용은 취소되지 않습니다.
2. **재개:** 같은 화면 → **Enable workflow**. 이후 예약 시간부터 동작하며 빠진 글을 몰아서 올리지 않습니다.
3. **게시하지 않는 미리보기:** **Run workflow** → `board=auto` 또는 특정 게시판 → `preview_only=true`. Artifact에만 생성하고 게시하지 않습니다. 별도 API 비용은 발생합니다.
4. **즉시 자동 게시:** **Run workflow** → `preview_only=false`. 자동 검수 통과 시 게시하며 하루 한도에 포함됩니다.
5. **실패 확인:** 해당 실행의 로그·검수·비용 파일부터 확인합니다. 같은 실행의 **Re-run**은 새 글을 생성하지 않습니다. 이미 게시된 글이면 공개 상태만 다시 확인합니다.

현재는 별도 추가 설정 없이 예약 실행을 기다리면 됩니다. AI 검수도 오류를 완전히 없애지는 못하므로 처음 며칠은 게시 결과와 비용을 함께 확인하는 것이 좋습니다.
